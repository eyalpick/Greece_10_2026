# כלל גיטהאב: דחיפת קוד אוטומטית (Auto Git Push)

המשתמש עובד במודל בו הוא אינו בוחן קבצים מקומית (Localhost) אלא צורך את האפליקציה ישירות דרך GitHub Pages.

**הוראה קריטית לכל משימה עתידית:**
לאחר כל משימה שבה ביצעת שינויים בקוד או בקבצי הפרויקט, חובה עליך להריץ באופן אוטומטי ויזום פקודות גיט כדי לדחוף את השינויים לשרת (origin). 
אל תשאל את המשתמש אם לעשות זאת - פשוט בצע:
1. `git add .` (או ציין את הקבצים הספציפיים).
2. `git commit -m "Your descriptive message"`
3. `git push`

לאחר הדחיפה המוצלחת, עדכן את המשתמש שהשינוי בוצע ושהוא נדחף בהצלחה ל-GitHub, והזכר שייתכן שייקחו דקה או שתיים עד שהשינוי יופיע באתר.
